## Context

Implements the [reviewed matrix](native_operation_audit_matrix.md) in the existing probe and
native tests. The 93 original IDs remain; N01-N35 add 35 cases, for 128 total. Expected outcomes
are contract-derived, never changed to match lane results. The matrix changed only in Python
code-block formatting to satisfy the repository formatter.

The probe separates setup, operation, inspection and explicit compute diagnostics; it checks
individual outputs, source-order label oracles, geometry order, fixed terms, transform and target
identity, complete index ownership, empty/scalar shapes, update values and refusal immutability.
Coordinate-only numerical inspection avoids pixel execution; actual lazy points construction is
also inspected. N29/N30 execute no pixel tasks before explicit compute. Field construction and
N31 refusal do not require SciPy; the N32 regression skips only its evaluating branch without
SciPy >=1.18. No test was skipped in these runs. Strict xfails use capability detection.

No xarray or src/xarrayrf files changed. No commits, branches, worktrees, git configuration,
network access or external-service actions were made. The JSON gate is unchanged: all non-ok
classifications, including pending_review, fail it.

## Current Decision

R1 is **not closed**. Series 4 fails N33: its second broadcast output has data dimensions y/channel
but carries x and a binding requiring x. The first output passes. A fix is needed in xarray's
excluded-dimension index propagation (patch 4 is a candidate area); no existing manifest patch
establishes ownership of this subcase. Do not fix this by changing the expected unframe outcome.

The two legacy refusal findings also persist in every lane:

- `broadcast_plane_volume`: design §3 forbids implicit plane/volume broadcast and the binding
  compatibility contract specifies ValueError / `incompatible framed coordinate mappings`.
  Xarray instead raises AlignmentError for conflicting y indexes before that check. The reviewer
  must decide refusal precedence/class; this implementation keeps the contract-derived assertion.
- `groupby`: binding_design's stack section specifies the geometry-stack veto (ValueError /
  `cannot stack geometry dimensions; call rf.unframe()`). The concrete operation instead reaches
  a corrupt-index refusal on y first. No expectation was relaxed to accept that earlier failure.

Legacy cases pending_review in **all lanes**, never counted ok:

- `rolling`: the contracts do not decide this rolling-window aggregation lifecycle or an exact
  refusal. The observed result reports framed, but that observation does not establish its contract.
- `interp`: design §4 documents a split binding rejected on inspection, while the strict audit
  requires an operation-time outcome. No exact operation-time refusal is specified. All lanes
  return a damaged binding and raise ValueError on inspection.

The existing matrix Q1 (an underspecified transform-index update candidate) remains outside this
work. N09 tests the reviewed unequal indexed-label refusal, not that candidate.
